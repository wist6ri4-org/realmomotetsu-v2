# 路線図チェッカー

東京メトロ v1 路線図の各駅マスをクリックして色を管理するローカルツールです。

## 起動方法

リポジトリのルートでローカルサーバーを起動してください。

```bash
# Node.js の場合
npx serve .

# Python の場合
python -m http.server
```

サーバー起動後、以下のURLにアクセスします。

```
http://localhost:3000/tools/routemap-checker/index.html
```

> ⚠️ HTMLファイルをブラウザで直接開いた場合（`file://`）、JSONの読み込みに失敗します。必ずローカルサーバー経由でアクセスしてください。

> HTMLファイル内の設定データを使用する場合は、ローカルサーバーを起動せずに直接開いても動作します。

---

## 使い方

### 駅マスの色変更

駅マスをクリックするたびに、以下の順で色が変わります。

```
未設定（白）→ 赤 → 青 → オレンジ → 未設定（白）→ ...
```

### データの保存

色の状態は自動的に **localStorage** に保存されます。
次回起動時も前回の状態が表示されます。

### データの共有

#### エクスポート
1. 画面上部の「📤 エクスポート」ボタンをクリック
2. 現在の状態がJSON形式でクリップボードにコピーされます
3. コピーしたテキストをLINEやSlackなどで相手に送ります

#### インポート
1. 画面上部の「📥 インポート」ボタンをクリック
2. 受け取ったJSONテキストを貼り付けて「インポート」をクリック
3. 相手と同じ状態が再現されます

### リセット

「🗑 リセット」ボタンをクリックすると全駅の色を初期状態（白）に戻します。
